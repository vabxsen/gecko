# Gecko — Curled Monogram

Selected direction: **3, Curled Monogram**, from the professional logo concepts.

- `gecko-curled-monogram.png`: selected concept reference.
- `gecko-monogram.svg`: editable, transparent white vector export.
- Production source: `core/designsystem/src/main/res/drawable/gecko_monogram.xml`.

The Android vector is shared by the Compose brand painter and both adaptive launcher icons. Launcher artwork uses a 10% inset to keep the silhouette within the circular mask; the background is `#111111`. In-app marks inherit the theme's foreground color. Earlier PNG concepts are exploratory references, not runtime assets.

Validation: signed release build succeeded; preview installed over v1.1.1. Visually checked the actual circular launcher icon and in-app mark in light and dark themes. Preview APK: `installer/gecko-logo-preview.apk`. Screenshots: `build/button-audit/curled-logo-{light,dark,launcher}.png`.

This logo is a local preview; the published v1.1.1 release has not been replaced.
